# Worker — prompt autonome si mode agent
Workdir /home/debian/.hermes/workspace/projects/investment-radar. Exécuter `./scripts/worker.sh` (aucune génération LLM, aucun ordre). Puis `python3 scripts/read-api.py /health`. Exiger une sortie status=ok et un last_worker.finished_at récent. Si status=degraded/failed, code non nul, worker verrouillé répétitivement ou health 503, signaler les erreurs réelles et IDs sans secrets, sans inventer de cours, sans transformer une absence de données en RED. Ne modifier aucune prédiction et aucun cron. Si mode script-only recommandé, le script exact est scripts/worker.sh et no_agent=true; l’agent n’est pas nécessaire. Cadence proposée every 30m (50 signaux par lot, ordre fair par calculated_at), jobs indépendants du rapport quotidien. Livraison d’état à configurer par le parent; pas de notification forcée dans le script.
